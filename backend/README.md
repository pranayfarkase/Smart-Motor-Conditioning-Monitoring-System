# Smart Motor Condition Monitoring System - Backend

This is the Node.js + Express backend server for the Smart Motor Condition Monitoring application. It provides API endpoints to serve telemetry, manage motors, track support tickets, and log events.

## Features

- **Express.js API Router**: Clean, structured REST endpoint routing.
- **Dataset Integration**: Serves the condition monitoring dataset generated by `extract_dataset.py` via the `/api/dataset` endpoint.
- **Motors API**: Provides reading and editing capability for connected motors.
- **Tickets & Logs System**: Stores local/session configurations for maintenance operations.

## Prerequisites

- [Node.js](https://nodejs.org/) (v16.0.0 or higher recommended)
- Python (with pandas and openpyxl libraries for extracting spreadsheets)

## Installation & Setup

1. **Install Dependencies**
   In the `backend` folder, run:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**
   Rename `.env` or check its values:
   - `PORT`: Server port number (default `5000`).

3. **Generate Dataset JSON**
   Ensure the downsampled JSON is created inside the frontend. From the project root, run:
   ```bash
   python extract_dataset.py
   ```

4. **Run Server**
   - **Development Mode** (with nodemon reload):
     ```bash
     npm run dev
     ```
   - **Production Mode**:
     ```bash
     npm start
     ```

## API Endpoints

- `GET /api/status` - Returns the server health status.
- `GET /api/dataset` - Returns the parsed Excel telemetry database records.
- `GET /api/motors` - Returns a list of monitored motors.
- `GET /api/tickets` - Returns a list of active maintenance tickets.
- `GET /api/logs` - Returns system event history.
